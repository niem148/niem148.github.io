I’ve just finished my MD102 Udemy course and it has given me a strong and practical understanding of Microsoft’s modern endpoint management tools. Throughout the course I set up Hyper V labs deployed Windows Server 2022 trial and Windows 11 virtual machines and built an on premise Active Directory environment that I later connected to Azure AD using Azure AD Connect. I purchased a trial of microsoft 365 E3 license to help with the labs.

I spent a lot of time working with Microsoft Entra ID and Intune including enrolling devices choosing the right join types configuring compliance policies and understanding how Conditional Access fits into the overall security model. I also created configuration profiles deployed applications set up Autopilot and managed updates across Windows, iOS macOS and Android.

The course covered endpoint security in depth including Defender for Endpoint onboarding security baselines LAPS for Entra ID and the remote actions available in Intune. By the end I had a clear view of how Windows clients are deployed secured updated and managed in a cloud first environment.

Overall it has been a comprehensive and hands on introduction to the tools and processes used by Microsoft Endpoint Administrators and it has given me a solid foundation to build on.
